# Running Coach 输出模板

## 通用守则

- 回答前先用一句话重述所问的问题，再给结论；问题里带具体时间、事件或数字的，重述必须带上原词（问"出签公布时间"不得答成"报名时间"）。
- 多个子问题逐条对应回答，不合并、不跳过；与所问无关的分析放最后或省略。
