# 环境数据源与置信度

环境数据用于解释配速、心率、体感、补给和安全风险。天气具有时效性；给真实训练建议时必须尽量获取当前或预报数据。

## 当前和未来训练

优先顺序：

1. 使用当前 agent 可用的天气工具查询计划地点和时间窗口。
2. 若只有城市级天气，标记置信度为 `中`。
3. 若只有季节或用户背景，标记置信度为 `低`，只给条件式建议。

需要字段：

- 温度。
- 相对湿度。
- 体感温度或露点。
- 风速/风向。
- 降水概率和雨量。
- 日照或云量。
- 用户要求时加入 AQI。

## 历史活动天气

历史活动需要匹配活动开始时间、地点或坐标。若当前工具环境没有历史天气 API，不要编造数值。

输出方式：

```text
环境：
- 时间/地点：
- 天气来源：
- 可能影响：
- 置信度：
- 缺失项：
```

可用历史天气源时，优先匹配小时级数据；只能匹配同城同日时，置信度为 `中`；只能根据城市和季节推断时，置信度为 `低`。

## 温度修正

马拉松和长距离对温度非常敏感。PLOS ONE 对大型马拉松数据的研究显示，气温是影响全马表现的重要因素，温度上升会降低速度并提高退赛率。用作背景，不机械套用。

实践规则：

- 凉爽干燥：允许配速目标更接近计划。
- 温度高于 26 C：轻松跑优先心率/体感，质量课降目标。
- 湿度高于 75% 或露点高于 18 C：提高热应激等级。
- 体感温度明显高于气温：按体感温度修正。
- 强风、大雨、湿滑路面：安全优先，避免硬追配速。

## 环境对训练安排的影响

高热湿时：

- 长距离改为时间制或缩短距离。
- 间歇延长恢复，减少组数。
- 马配段改为马拉松努力感或心率上限。
- 增加饮水和电解质计划。

凉爽天气下：

- 同心率配速更快可能是天气收益，不要直接判定体能大幅提升。
- 比赛预测仍要结合路线、风、补给和起跑拥挤。

旅行或城市变化时：

- 先考虑睡眠、饮食、出差疲劳、气候差异和路线陌生。
- 不同城市活动不要直接用平均配速横向比较。
